# AM Digits – Calculator

A modern, lightweight, web-based calculator designed to perform basic mathematical operations with a clean UI and smooth DOM-based interactions.

## 🌐 Live Demo

Experience it here: **[https://am-digits.netlify.app/](https://am-digits.netlify.app/)**

---

## ✨ Features

- **Fully functional calculator interface**
- **Supports:**
  - Addition, Subtraction, Multiplication, Division
  - Percentage & Clear options
- **Real-time input and result display**
- **Click-based interaction through buttons**
- **Error handling for invalid expressions**
- **Responsive layout for different screen sizes**

---

## 🧠 Key Concepts Used

This project is built using **JavaScript DOM Manipulation**, including:

- Selecting elements (`querySelector`, `getElementById`)
- Handling events (`addEventListener`)
- Updating text and styles dynamically
- Conditional execution to control display logic

---

## 🛠️ Technologies

- **HTML** – Structure
- **CSS** – Styling & Layout
- **JavaScript** – Functionality & DOM Logic
